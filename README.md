# wifit3 Termux Setup

Setup for running wifit3 on rootless Termux with adapters like the RTL8812AU.

Huge thanks to [derv82](https://github.com/derv82) for creating [wifit3](https://github.com/derv82/wifit3), the actual tool this setup wraps.

## Installation
```bash
git clone https://github.com/rehimlianar/wifit3-termux-setup.git ~/wifit3-termux-setup
cd ~/wifit3-termux-setup
bash install.sh
source ~/.bashrc
```

## Usage
```bash
wifit3-run
```
